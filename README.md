## 🏥 Smart Healthcare App

### 📱 Overview

Smart Healthcare App is a full-stack Android application designed to digitally connect **Patients, Doctors, Hospitals, and Admin** on a single platform.
The app simplifies hospital onboarding, doctor slot management, and patient appointment booking using a secure **admin-approval–based workflow**.

This project reflects **real-world healthcare system design** with scalable architecture and role-based access control.

---

## 🎯 Project Objectives

* Digitize healthcare management processes
* Enable admin-controlled hospital onboarding
* Simplify doctor appointment scheduling
* Provide easy hospital discovery for patients
* Build a scalable, production-ready healthcare platform

---

## 👥 User Modules & Features

### 🧑‍⚕️ Patient Module

* Search hospitals by location
* View hospital details (specialties, facilities, technologies)
* Book doctor appointments
* View appointment history
* Request blood assistance

---

### 👨‍⚕️ Doctor Module

* Submit doctor profile details
* Add and manage available time slots
* View patient appointment requests
* Manage daily schedules

---

### 🏥 Hospital Module

* Hospital login and registration
* Submit access request to admin
* Dashboard access only after approval
* Manage hospital profile:

  * About hospital
  * Specialties and facilities
  * Advanced medical technologies (with images)
  * Address and contact information
* Upload hospital logo and technology images

---

### 🛡️ Admin Module

* View hospital access requests
* Approve or reject requests
* Maintain request status (Pending / Approved / Rejected)
* Store approval metadata (admin name, date, reference ID)

---

## 🔄 Application Workflow

1. Hospital submits access request
2. Admin reviews and updates request status
3. Approved hospitals gain dashboard access
4. Doctors add available time slots
5. Patients search hospitals and book appointments

---

## 🛠️ Tech Stack

### Android

* Kotlin
* XML (Material Design)
* Retrofit (API integration)
* RecyclerView, Fragments, ViewPager2
* Multipart image upload

### Backend

* PHP (RESTful APIs)
* MySQL Database
* XAMPP Server
* JSON & Multipart Form Data

---

## 🗄️ Database Design Highlights

* Dynamic hospital profile storage
* Doctor slot timings stored efficiently
* Status-based request tracking
* Secure storage of uploaded image paths

---

## 🧪 How to Run the Project

### Android App

1. Clone the repository
2. Open the project in **Android Studio**
3. Sync Gradle files
4. Run on emulator or physical device

### Backend

1. Install **XAMPP**
2. Place PHP files in `htdocs`
3. Import the MySQL database
4. Update API base URL in the Android app

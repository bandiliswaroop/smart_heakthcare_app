## 📱 Project Overview

**Smart Healthcare App** is a full-stack Android application developed to digitally connect **Patients, Doctors, Hospitals, and Admin** on a single platform.

The application simplifies hospital onboarding, doctor slot management, and patient appointment booking through a secure **admin-approval–based workflow**, reflecting real-world healthcare system design.

---

## 🎯 Project Objectives

- Digitize healthcare management processes  
- Enable admin-controlled hospital onboarding  
- Simplify doctor appointment scheduling  
- Improve hospital discovery for patients  
- Build a scalable and production-ready healthcare platform  

---

## 👥 User Modules & Features

### 🧑‍⚕️ Patient Module
- Search hospitals by location  
- View hospital details (specialties, facilities, technologies)  
- Book doctor appointments  
- View appointment history  
- Request blood assistance  

### 👨‍⚕️ Doctor Module
- Create and manage doctor profiles  
- Add and manage available consultation slots  
- View patient appointment requests  
- Organize daily schedules  

### 🏥 Hospital Module
- Hospital registration and secure login  
- Submit access requests for admin approval  
- Dashboard access only after approval  
- Manage hospital profile:
  - About hospital  
  - Specialties and facilities  
  - Advanced medical technologies (with image uploads)  
  - Address and contact details  
- Upload hospital logo and technology images  

### 🛡️ Admin Module
- Review hospital access requests  
- Approve or reject onboarding requests  
- Maintain request statuses (Pending / Approved / Rejected)  
- Track approval details (admin name, date, reference ID)  

---

## 🔄 Application Workflow

1. Hospital submits access request  
2. Admin reviews and updates request status  
3. Approved hospitals gain dashboard access  
4. Doctors add consultation slots  
5. Patients search hospitals and book appointments  

---

## 🛠️ Technology Stack

### 📱 Android
- Kotlin  
- XML (Material Design)  
- Retrofit (REST API integration)  
- RecyclerView, Fragments, ViewPager2  
- Multipart image upload  

### 🌐 Backend
- PHP (RESTful APIs)  
- MySQL Database  
- XAMPP Server  
- JSON and Multipart Form Data  

---

## 🗄️ Database Design Highlights

- Dynamic hospital profile storage  
- Optimized doctor slot timing storage  
- Status-based hospital request tracking  
- Secure handling of uploaded image paths

## 🧪 How to Run the Project

### Android Application
1. Clone this repository  
2. Open the project in **Android Studio**  
3. Sync Gradle dependencies  
4. Run on an emulator or physical device  

### Backend Server
1. Install **XAMPP**  
2. Place PHP files inside `htdocs`  
3. Import the MySQL database  
4. Update the API base URL in the Android app
